# 独立站全流程 Skills

独立站相关 Skills 的总仓库。每个 Skill 放在 skills/ 下的独立子文件夹中，方便上传、维护和按需使用。

## 目录结构

```text
independent-site-workflow-skills/
├── README.md
└── skills/
    └── README.md
```

目前已建立目录和说明，具体 Skills 待上传。

## 上传与使用

进入 [skills 子文件夹](./skills/) 查看上传指引。后续每上传一个 Skill，就在 skills/ 下保留它自己的完整文件夹，例如 skills/website-audit/SKILL.md；此路径仅为示例。

使用者可以点击 Code → Download ZIP 下载总仓库，解压后取出需要的完整 Skill 文件夹，按目标工具的安装方式使用。请保留配套脚本、参考资料和素材，并按照各 Skill 说明配置依赖。

上传第三方 Skill 时，请保留原作者署名及许可证，并遵循其授权条款。
