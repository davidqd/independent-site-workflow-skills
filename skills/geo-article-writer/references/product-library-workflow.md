# 产品库驱动工作流

用户提供产品库 Excel，并要求按产品和关键词生成选题或写文章时使用本规则。

## 1. 识别工作簿结构

- 逐个检查可见工作表、表头、合并单元格、公式和数据行，不默认第一张表就是产品表。
- 识别产品名称、产品 ID/SKU/型号、关键词列及产品参数列。表头可以是中英文或业务自定义名称，应根据单元格语义映射。
- 一个单元格包含多个关键词时，仅在关键词列内按换行、分号、逗号或竖线拆分；去除首尾空格和完全重复项，不拆分参数文本。
- 每个产品优先使用产品库中的稳定 ID；没有 ID 时使用“工作表名 + 原始行号”作为可复核标识，不编造 SKU。
- 空白产品名、空白关键词和明显的说明/小计行不进入选题矩阵，并在结果中报告跳过数量与原因。

## 2. 建立产品关键词矩阵

每个有效组合保存：

- `产品ID`
- `产品名称`
- `产品关键词`：产品库中拆分出的原始关键词
- `产品库文件`
- `产品库工作表`
- `产品库行号`：Excel 的一基行号
- `产品参数依据`：仅记录当前产品行中非空的参数，使用 `字段=值` 形式并保留单位

不要把同名但不同型号的产品合并。产品名称相同且产品 ID 不同的行，仍视为不同产品。

## 3. 为每个组合生成四个主题

对每个“产品 × 产品关键词”组合恰好生成：

- Attention：问题认知、定义、风险、趋势或早期需求；通常为信息型。
- Interest：原理、应用、使用方法、选择条件或深入理解；通常为信息型或商业调研型。
- Desire：价值、证据、比较、总成本、适配性、风险与异议处理；通常为商业调研型。
- Action：询价、规格确认、采购清单、供应商评估、打样或实施步骤；通常为交易型。

四个标题必须是四种真实搜索角度，不能只在同一标题前添加 A/I/D/A 标签。`产品关键词` 保留原始词，`主关键词` 可以是该阶段更具体的长尾查询。相同产品关键词的四条主题允许共享原始词，但不得共享完全相同的标题、核心用户问题和阶段意图表达。

## 4. 参数使用边界

- 选题只能引用当前产品行确实存在的参数。例如表格有 `Active content=60%`，才可规划包含 60% 的主题。
- 产品库没有的具体参数，不得从搜索结果、相似产品或行业常见值补入产品主题。
- 外部官方资料可用于法规、术语和通用原理，但必须与产品专属参数分开记录。
- 参数缺失、冲突、单位不明或公式无可用结果时，将该字段标记 `待确认`；涉及该参数的主题不得进入自动写作队列。

## 5. 数量与验收

有效组合数为 `N` 时，基础选题数必须为 `4 × N`。若用户同时要求不少于 200 条，则至少需要 50 个有效组合。组合不足时报告差额，优先让用户补充关键词；未经用户同意，不为单一阶段复制额外主题凑数。

创建或验证队列时使用 `--require-product-aida`。验收需确认每个组合 A/I/D/A 各一条、来源行可回查、参数依据非空，以及没有标题重复。
