# WordPress 每日草稿自动化

用户要求每天从 Excel 队列创建 WordPress 草稿时读取本文件。

## 首次配置清单

- 精确的网站 URL 和 WordPress 连接身份
- Excel 选题库绝对路径、工作表和可写权限
- 每日运行时间与时区；默认每日处理 3 条，不默认具体时刻
- 文章语言、作者、分类、标签、slug 规则和摘要要求
- SEO 插件及可写的 Meta Title、Meta Description、canonical 字段
- 网站真实产品页、服务页、案例页、资源页和联系页
- 已验证的 CTA、表单短代码或组件
- 图片来源、特色图要求和媒体上传能力

首次配置时建立可复核的站内链接池，至少保存页面标题、规范 URL、页面类型、主题或产品归属和可用语言。链接优先级为：相关关键词对应的产品详情页、对应产品分类页、Home 页；只使用已发布且可访问的页面。图片配置还需明确允许的来源（用户素材、品牌素材、生成图片或授权图库）、视觉风格、尺寸、文件格式和版权边界。

任何网站身份、分类 ID、表单 ID、作者、链接或凭据都不得猜测。配置中不要记录或输出明文密钥。

## 单次每日运行

1. 读取并验证工作簿，确认没有损坏且存在未处理话题。
2. 使用队列脚本按优先级认领最多 3 条；不要并行认领或回写。
3. 对每条话题读取完整 brief，而不是只读取标题。
4. 必要时补充事实研究，但不得擅自改变主关键词、搜索意图、AIDA 阶段、目标受众或市场定位。
5. 按 GEO 写作规则生成文章，同时准备最终标题、slug、摘要、Meta Title、Meta Description、内部链接和 CTA。
6. 从站内链接池自动加入不超过 5 个锚文本内链。优先选择与相关关键词对应的产品详情页和产品分类页，并加入 Home 页；锚文本须准确描述目标页面，同一 URL 通常只链接一次，禁止无意义的“点击这里”和虚构 URL。
7. 为每篇文章自动生成或选择至少 1 张特色图。图片不得虚构产品外观、认证、参数、人物身份或效果；产品实拍只能使用用户或品牌提供的已验证素材。为图片准备语义化文件名、媒体标题和描述性 Alt 文本，通过媒体工具上传并保存媒体 ID。正文图只在能解释结构、步骤、比较或应用时添加。
8. 创建前检查 Excel 的 WordPress 内容 ID，并按 slug 和标题查询现有文章。已有同一草稿时验证并复用，避免重复。
9. 创建 WordPress 文章，明确 `status=draft`，设置目标分类与特色图媒体 ID。用户未明确授权时不得发布或定时发布。
10. 读回文章并验证：
   - WordPress 内容 ID 存在
   - 状态为 `draft`
   - 标题、slug 和正文与本次话题对应
   - 正文非空，标题层级和主要章节完整
   - 主关键词自然出现，Meta 字段在工具支持时已填写
   - 关键内部链接、CTA、分类和标签正确
   - 锚文本内链不超过 5 个；已加入相关产品详情页、产品分类页和 Home 页中当前站点实际存在且与文章相关的目标
   - 每个内链 URL 可访问、语言版本正确，锚文本与目标页相关
   - 特色图媒体 ID 存在并关联当前草稿，图片 Alt 文本非空且准确；正文图片如有，其位置与上下文匹配
   - 不含内部提纲、假设、制作说明或机械 AI 标签
11. 文章、内链和图片全部验证成功后，立即串行回写该行 `草稿已创建`、完成日期、草稿链接、WordPress 内容 ID 和最终标题。
12. 图片生成、上传、特色图关联或内链验证失败时，串行回写 `失败待重试` 与可操作错误说明；不得留下伪成功状态。

## 幂等与恢复

- 如果任务在 WordPress 创建成功后、Excel 回写前中断，下次必须先按内容 ID、slug 和标题查重。
- 找到匹配草稿且验证通过时，只补写 Excel，不再创建新文章。
- `写作中` 状态不应永久搁置。人工确认没有对应草稿后，可改为 `失败待重试`；不要未经检查直接重新创建。
- 同一次运行最多尝试 3 条已认领话题，避免失败重试导致超过每日范围。

## 排程提示词模板

将以下内容放入 Codex 排程任务，并替换占位符：

```text
使用 $geo-article-writer 执行 WordPress 每日草稿工作流。

项目目录：<PROJECT_DIRECTORY>
Excel 选题库：<ABSOLUTE_XLSX_PATH>
工作表：<SHEET_NAME>
WordPress 目标：<SITE_URL_OR_VERIFIED_CONNECTION>
每日数量：3
目标状态：draft
语言：<LANGUAGE>
分类/作者/标签规则：<RULES>

按优先级认领最多3条待处理或失败待重试话题，逐篇生成符合SEO和GEO要求的文章。每篇从已验证站内页面池自动加入不超过5个自然锚文本内链，优先链接相关关键词对应的产品详情页、产品分类页，并加入Home页；不得虚构URL。每篇自动生成或选择至少1张主题相关特色图，写入准确Alt文本，上传媒体库并关联草稿；正文图仅在有解释价值时添加。创建前查重，创建后读回验证文章、分类、内链数量与目标、媒体ID、特色图和Alt文本。全部成功后立即串行回写“草稿已创建”、完成日期、草稿链接、WordPress内容ID和最终标题；失败则回写“失败待重试”和错误说明。禁止发布文章，禁止猜测网站ID、分类、表单、链接、图片事实或业务事实。
```

首次启用排程前，在普通任务中手动执行一次，人工检查至少 3 篇草稿。排程任务需要可访问本机项目、Excel 文件和 WordPress 工具；本机项目还要求电脑开机且桌面应用持续运行。
