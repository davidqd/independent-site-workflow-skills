# B2B 白帽外链开发 Skill

用于为外贸制造商、工业品供应商、批发商和 OEM/ODM 企业发现、验证、评分并跟进白帽外链机会。

## 安装到 Codex

复制下面的提示词发送给 Codex：

```text
使用 $skill-installer，从下面的 GitHub 地址安装 Skill。请保留完整目录结构，安装后检查文件是否完整，并告诉我如何调用。

https://github.com/davidqd/independent-site-workflow-skills/tree/main/skills/b2b-backlink-builder
```

也可以按照仓库的 [Codex Skills 安装说明](../../CODEX-INSTALL.md) 手动安装。安装时不要只复制 `SKILL.md`，应保留 `agents/`、`references/`、`scripts/` 和 `LICENSE.md` 等配套文件。

## 使用

```text
使用 $b2b-backlink-builder，为 qpdryer.com 寻找免费的工业干燥设备相关外链机会。
```

Skill 默认自动化调研、验证、评分和外联准备，不会自动发送邮件、注册账号、投稿或付款。涉及对外发送或提交前，需要人工审核和明确确认。

## 更新

重新下载最新版，用新的完整文件夹替换本地旧版本。替换前请备份自己修改过的文件和活动数据。
