# B2B 白帽外链开发

## 目标

把外链工作转化为可审核的 B2B 业务开发流程：先发现真实机会并保留证据，再评估相关性、编辑质量和风险，最后生成个性化外联材料。默认自动化调研与准备，不自动发送、注册、投稿或付款。

## 开始前

尽量收集或从官网推断：

- 我方网站、品牌、产品及标准英文市场名称。
- 目标国家/语言、买家类型和重点产品页。
- 可用于换取链接的真实资产，如技术指南、选型表、测试数据、证书、案例、原创图片或专家观点。
- 已知竞品域名、排除域名和已有外链导出。

信息不足时先做小规模探索，把未知字段标为 `待确认`，不要虚构公司能力、数据或合作条件。

## 工作模式

- `机会发现`：寻找并验证潜在外链来源。
- `竞品差距`：从可靠工具导出或公开证据中找竞品已有、我方缺失的来源。
- `外联准备`：查找公开商务联系人并生成一对一外联稿。
- `活动跟进`：更新发送、回复、谈判、上线和复查状态。
- `现有外链审计`：识别失效链接、错误目标页、低相关性和明显风险来源；不擅自请求删除或提交 disavow。

## 执行流程

### 1. 建立活动目录

需要结构化交付时运行：

```bash
python3 scripts/backlink_campaign.py init \
  --output-dir <campaign-directory> \
  --site <company-domain> \
  --product "<product>" \
  --market "<target-market>"
```

该命令创建 `campaign.json`、`prospects.csv` 和 `outreach_log.csv`；如目标文件已存在则停止，避免覆盖用户数据。

### 2. 发现机会

按优先级搜索：

1. 与产品和目标市场直接相关的行业协会、标准组织、专业目录和展会资源。
2. 经销商、安装商、工程伙伴、供应链伙伴和客户允许公开的供应商/品牌页。
3. 专业媒体、采购指南、资源页、客座内容、采访、播客和专家征稿。
4. 竞品已有外链、未链接品牌提及、失效资源页和 broken-link replacement。
5. 本地商会、出口机构、认证机构的合规企业名录。

搜索语法、证据要求和输出字段见 [references/scoring-and-output.md](references/scoring-and-output.md)。不得把搜索结果摘要当成已验证页面；打开来源页并记录实际 URL、页面类型、证据和采集日期。

### 3. 验证与评分

逐条确认：

- 页面和域名与产品、行业、买家或目标市场的相关性。
- 来源是否具有真实编辑、受众和更新痕迹，而非专门售卖链接的站群。
- 页面是否允许合理的供应商收录、专家贡献、资源补充或商业合作。
- 链接落点是否自然，应优先指向真正有用的产品、解决方案、数据或指南页。
- 联系方式是否为公开商务渠道，且适合当前合作诉求。

使用参考文件中的 100 分模型。没有 Ahrefs、Semrush、Moz、Keywords Everywhere 或同类可靠数据时，把流量、权重和外链指标写为 `未提供/待查询`，不得猜数。

已有候选 CSV 时可运行：

```bash
python3 scripts/backlink_campaign.py score \
  --input prospects.csv \
  --output prospects_scored.csv
```

### 4. 准备个性化外联

先说明真实关联，再提出对对方受众有用的具体价值。每封文案必须引用该网站的实际页面或栏目，并只提出一个明确动作。模板和可接受的价值交换见 [references/outreach-playbook.md](references/outreach-playbook.md)。

禁止：

- 批量发送未经个性化的邮件或表单。
- 伪装身份、伪造客户案例、数据、证书或编辑关系。
- 购买未披露的传递排名权重链接，或要求对方隐藏商业关系。
- 自动注册账号、绕过验证码、批量评论或向无关目录灌链。
- 承诺排名、流量或 AI 引用结果。

### 5. 人工审核与执行

发送、提交、注册、付费、交换资源或代表公司承诺合作前，必须向用户展示：

- 目标网站、目标联系人和公开来源。
- 拟发送的完整文案与链接落点。
- 合作条件、可能费用和是否需要披露/`rel="sponsored"`。
- 风险信号及推荐动作。

只有得到明确确认后才能使用可用邮件、CRM 或浏览器工具执行对应动作。一次确认只覆盖已展示的具体批次，不扩展到后续名单。

### 6. 跟进与复查

把状态限制为：`待验证`、`待审核`、`已批准`、`已发送`、`已回复`、`谈判中`、`已上线`、`拒绝`、`无回复`、`需复查`。上线后记录实际链接 URL、目标页、锚文本、链接属性和首次发现日期，并在 30-90 天内复查是否仍可访问。

## 交付要求

至少提供：

1. `data_coverage`：哪些来源已验证、部分验证或未取得数据。
2. `prospects.csv`：逐条机会、证据、评分、风险和下一步。
3. `outreach_log.csv`：联系人来源、审核状态、文案和跟进记录。
4. 中文摘要：A级机会、可立即准备的资产、被拒绝的高风险来源及原因。

区分 `已观察事实`、`第三方估算`、`基于证据的推断` 和 `待确认`。数量不能替代质量；默认先交付 20-50 个高度相关且可复核的机会，而不是数百个未验证域名。

## 快速调用示例

- `用 $b2b-backlink-builder 为工业冷水机在美国找 30 个白帽外链机会。`
- `用 $b2b-backlink-builder 分析这 5 个竞品的外链差距，只保留能联系到编辑或协会的来源。`
- `用 $b2b-backlink-builder 根据 prospects.csv 评分，并为 A 级机会生成英文外联邮件。`
