# B2B WordPress 建站 Skill

用于规划、搭建、重构并验收外贸 B2B WordPress 独立站，强调后台可视化维护、主题原生组件复用和发布前验收。

## 下载

1. 回到[总仓库首页](https://github.com/davidqd/independent-site-workflow-skills)。
2. 点击 **Code → Download ZIP**。
3. 解压后找到 `skills/build-b2b-wordpress-site`。
4. 复制整个 `build-b2b-wordpress-site` 文件夹，不要只复制 `SKILL.md`。

## 安装到 Codex

将完整文件夹复制到个人 Skills 目录：

- macOS / Linux：`~/.codex/skills/build-b2b-wordpress-site/`
- Windows：`%USERPROFILE%\.codex\skills\build-b2b-wordpress-site\`

安装后重新打开 Codex或新建任务，让 Codex 重新发现 Skill。确认 `SKILL.md`、`agents/`、`references/`、`LICENSE.md` 和本说明仍在同一个文件夹中。

## 使用

在 Codex 中直接说明任务并点名 Skill：

```text
使用 $build-b2b-wordpress-site，为这个外贸制造企业规划并搭建 WordPress B2B 独立站。
```

只做页面规划时可以直接使用。实际写入 WordPress、读取主题 Pattern、设置 ACF、表单或进行发布验收时，还需配置可访问目标网站的 WordPress 工具和登录权限。

## 更新

重新下载最新版，用新的完整文件夹替换本地旧版本。替换前请备份自己修改过的文件。
